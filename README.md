# 🌧️ Japanese Type Game (日本語タイピングゲーム)

일본어 단어를 타이핑하여 떨어지는 단어를 맞추는 산성비 스타일의 타자 연습 게임입니다.  
日本語の単語をタイピングして、落ちてくる単語を当てるタイピングゲームです。

## 🚀 바로 플레이하기 / プレイはこちら
[https://aca1122.github.io/JapaneseTypeGame/](https://aca1122.github.io/JapaneseTypeGame/)

---

## 🎮 게임 방법 (Korean)
1. **시작**: 입력창에 **'시작'**이라고 입력하고 **Enter**를 누르면 게임이 시작됩니다.
2. **플레이**: 위에서 떨어지는 일본어 단어를 보고, 그에 맞는 **한국어 뜻**을 입력창에 타이핑하세요.
3. **콤보**: 3번 연속으로 정답을 맞추면 라이프(Life)가 1 회복됩니다 (최대 3개).
4. **종료**: 단어가 바닥에 닿아 라이프가 0이 되면 게임이 종료되며, 틀린 단어 목록이 표시됩니다.

## 🎮 遊び方 (Japanese)
1. **スタート**: 入力欄に **「시작」** (開始) と入力して **Enter** を押すとゲームが始まります。
2. **プレイ**: 上から落ちてくる日本語の単語を見て、その **韓国語の意味** を入力欄にタイピングしてください。
3. **コンボ**: 3回連続で正解すると、ライフ (Life) が1回復します (最大3つ)。
4. **終了**: 単語が地面に触れてライフが0になると終了です。終了後、間違えた単語のリストを確認できます。

- `RainType.js`: 게임 구동 로직
- `RainDictionary.js`: 단어장 데이터
